# TripSync 2 architecture audit

The Public App is this repository (Next 16.3.5 App Router); Chain Studio is `../tripsync-chain-studio`; Admin is `../trypsync-admin`. Chucklesome is excluded. All three share Supabase authentication and PostgreSQL. Existing trip IDs are bigint; itinerary IDs and profile IDs are UUIDs. Owner plus `trip_members` determine access, with `collaborationAccess` adding explicit membership checks independently of administrative read permissions.

Public routes include `/trips/[tripId]`, generation, revision/proposals, feedback/votes, preferences, members/invitations and manual editing. `itinerary_versions`, `itinerary_items`, activity votes, preference snapshots, and `itinerary_proposals` already provide immutable history, parent relationships and scope-limited revisions. `save_itinerary_proposal` and `apply_itinerary_proposal` enforce preview/confirmation, owner application, preference conflicts and serialized publication. Reuse these rather than introducing another version engine. Ratings remain on original versions.

`lib/gemini.ts` delegates to `runPublishedChain` when Studio is enabled. The secret-authenticated `studio_gateway` records exact publication snapshots, steps, routing decisions and generation/proposal relationships. Destination country resolution and published global/North America/Europe/China workflows remain unchanged. Multi-country ambiguity continues to use the existing recorded global fallback policy. Studio retains React Flow and its publication/routing APIs. Admin `/generations` already shows run status, chain/publication IDs, region, latency and actual feedback; no private chat or expense read access is needed.

Existing SQL lives in `sql/` as reviewed installation scripts, rather than Supabase CLI migrations. Existing PGlite tests execute real SQL/RLS on representative schemas. Vercel project links exist in each repository; deployment metadata is documented in `docs/ecosystem-deployments.json`. Local environment has Gemini/Google Places/Studio configuration, but no flight/hotel supplier credential. Travel discovery therefore uses explicitly labeled external search links with no inventory, availability or prices.
