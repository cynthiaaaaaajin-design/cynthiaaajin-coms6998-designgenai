# TripSync original motion artwork

`travel-loop.mp4` and `travel-poster.webp` are original procedural illustrations
created for this repository. No stock footage, third-party photos, music, or
external artwork is used. The silent four-second, 640×400 H.264 loop animates
clouds, water, and a sailboat. The WebP poster is the first frame.

Replace only with footage you own or have licensed. Keep the same filenames,
small dimensions/file size, and a matching poster. `LANDING_VIDEO_ENABLED=false`
restores the existing static destination illustration. Mobile, reduced-motion,
data-saver, and slow-connection users receive only the poster by default.
